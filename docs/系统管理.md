# 系统管理模块

> 覆盖：登录认证、SSO 接入、用户管理、角色权限、系统设置、审计、仪表盘、监控、菜单、健康检查

## 功能概览

| 子功能 | 说明 |
|---|---|
| 登录认证 | 本地账号密码 / SSO / 双因子（TOTP），Redis 会话 + 滑动续期 + 登录限流 |
| SSO 接入 | 对接统一鉴权中心（authPlatform），HMAC 签名调用、用户同步与映射 |
| 用户管理 | 用户列表/编辑、认证中心用户同步、TOTP 密钥管理（创建/删除/重置已禁用） |
| 角色权限 | 内置角色、权限码体系、管理员权限自动补全 |
| 系统设置 | 四标签页设置（部署环境/Nginx/中间件/平台），连通性测试 |
| 审计 | 全局写操作自动拦截记录，操作轨迹查询 |
| 仪表盘 | 首页项目/环境/构建等聚合统计 |
| 监控 | 整体健康 / 单卡监控 / SSE 实时推送 |
| 菜单 | 菜单树与权限单一来源，按角色返回可见菜单 |
| 健康检查 | 六维度运行状态检查 |

## 认证机制（纯 Redis）

- **会话存储**：登录成功后将用户快照（含权限）写入 Redis `ops:platform:auth:token:{token}`，MySQL 不再有 `auth_tokens` 表。
- **滑动续期**：每次有效请求重置会话 TTL 为 `token_expire_hours`（平台设置，默认 8 小时）；闲置超时自动过期。
- **单点登录**：同一用户新登录会清除其旧会话，只保留最新一次登录。
- **失效场景**：登出、修改密码、禁用用户、删除用户、角色权限变更均会删除对应 Redis 会话。
- **登录限流**：同一用户名连续失败 5 次锁定 15 分钟（Redis 计数）。
- **故障表现**：Redis 不可用时认证不可用（无 DB 兜底），恢复后需重新登录。

### 登录方式

- **本地登录**：账号密码，支持平台配置的双因子（TOTP）两步校验。
- **管理员本地登录**：`super_admins` 独立账号表，`admin-login` 入口，与业务用户体系隔离。
- **SSO 登录**：对接统一鉴权中心，支持单步（账号密码 / 用户名 + TOTP）与两步登录，详见 authPlatform 接入文档。

## SSO 接入（authPlatform）

统一鉴权中心接入由 `modules/system/auth_platform.py` 实现，作为客户端：

- **签名**：所有平台侧接口使用 HMAC 签名（共享密钥 `platform_secret`）。
- **校验**：`verify_login` / `verify_login_totp` / `verify_login_step2` 分别对应单步与两步登录校验。
- **用户同步**：`sync_users` 拉取认证中心用户，映射到本地 `users` / `synced_users`。
- **首次登录映射**：`get_or_create_sso_user` 按用户名自动创建本地用户并绑定认证源。
- **资料变更**：`update_profile` 将本地资料变更转发回认证中心。

详细协议见「authPlatform接入文档.md」，方案设计见「统一鉴权中心设计.md」。

## 密码规则

由「平台设置」控制，创建用户、重置密码、修改密码统一校验：

- `password_min_length`：最小长度（默认 6）
- `password_require_upper`：是否必须含大写字母（0/1）
- `password_require_digit`：是否必须含数字（0/1）

## 角色权限

- 权限码定义：`modules/system/permissions.py`（`ALL_PERMISSIONS` / `BUILTIN_ROLES`）。
- 管理员角色启动时自动补全新增权限码，保证"拥有全部权限"。
- 内置角色与默认管理员 `admin/admin123` 由 `core/bootstrap.py` 种子数据初始化。
- 菜单与权限以 `menus` 表为单一来源，角色权限与菜单可见性联动。

## 系统设置（四标签页）

设置项按 `settings.type` 列分组（`deploy` / `nginx` / `middleware` / `platform`）：

- `GET /api/settings/list?type=deploy|nginx|middleware|platform` 按组返回，不带 type 返回全部。
- 设置直连 MySQL 读取（无 Redis 缓存）；密码类字段不返回明文。
- `agent_comm_secret` 为只读字段，接口禁止修改（改动会导致所有 Agent 通讯失效）。
- 提供 SSH / Harbor 等连通性测试接口（`test-ssh` / `test-k8s-ssh` / `test-nginx-ssh` / `test-harbor`）。

## 审计

- `core/audit.py` 注册全局写操作拦截器，自动记录管理操作轨迹。
- 采集操作人、操作模块、动作、目标、字段 diff，敏感字段脱敏。
- `audit_api.py` 提供分页筛选查询与模块枚举（`/api/audit/list`、`/api/audit/modules`）。
- 审计日志落库 `audit_logs` 表。

## 仪表盘

- `GET /api/dashboard/stats`：聚合项目数、环境数、构建数等首页统计指标。

## 监控

- `GET /api/dashboard/monitor/health`：整体健康状态。
- `GET /api/dashboard/monitor/<key>`：单卡监控详情。
- `GET /api/dashboard/monitor/stream`：SSE 实时推送监控数据。

## 菜单

- `GET /api/menus`：返回当前用户可见的菜单树。
- 菜单数据由 `menu_seed.py` 初始化，与权限体系共用 `menus` 表。

## 健康检查

`modules/system/healthz.py` 实现六维度检查，`run_checks` 汇总：

- database：数据库连通性
- redis：Redis 连通性
- thread_pool：线程池状态
- task_queue：任务队列状态
- event_loop：事件循环 / 调度延迟
- downstream：下游依赖健康

在 `app.py` 中注册请求耗时采样钩子，用于事件循环 / 调度延迟维度统计。

| `synced_users` | 认证中心用户只读副本 |

| `super_admins` | 超管独立账号表 |

## 主要接口

- 认证：`POST /api/auth/login`、`/login-2fa`、`/admin-login`、`/logout`、`GET /me`、`POST /change-password`
- 用户：`GET /api/users/list`、`POST /update/<id>`、`POST /sync`、`GET /synced`、`POST /profile/<id>`、`POST /totp-setup/<id>`
- 角色：`GET /api/roles/list`、`/detail/<id>`、`POST /create|/update/<id>|/delete/<id>`、`GET /permissions`
- 设置：`GET /api/settings/list`、`POST /update`、`GET /debug`、`POST /test-ssh|/test-k8s-ssh|/test-nginx-ssh|/test-harbor`
- 审计：`GET /api/audit/list`、`/modules`
- 仪表盘：`GET /api/dashboard/stats`
- 监控：`GET /api/dashboard/monitor/health`、`/monitor/<key>`、`/stream`
- 菜单：`GET /api/menus`
- 健康检查：`GET /health`（含 Redis 状态）

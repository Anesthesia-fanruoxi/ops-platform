# 系统管理模块

> 覆盖：登录认证、用户管理、角色权限、系统设置

## 功能概览

| 子功能 | 说明 |
|---|---|
| 登录认证 | 账号密码登录，Redis 会话 + 滑动续期 + 登录限流 |
| 用户管理 | 用户增删改、启用/禁用、重置密码、昵称 |
| 角色权限 | 内置角色、权限码体系、管理员权限自动补全 |
| 系统设置 | 四标签页设置（部署环境/Nginx/中间件/平台），按 `settings.type` 分组 |

## 认证机制（纯 Redis）

- **会话存储**：登录成功后将用户快照（含权限）写入 Redis `ops:platform:auth:token:{token}`，MySQL 不再有 `auth_tokens` 表。
- **滑动续期**：每次有效请求重置会话 TTL 为 `token_expire_hours`（平台设置，默认 8 小时）；闲置超时自动过期。
- **单点登录**：同一用户新登录会清除其旧会话，只保留最新一次登录（旧 token 立即失效）。
- **失效场景**：登出、修改密码、禁用用户、删除用户、角色权限变更均会删除对应 Redis 会话。
- **登录限流**：同一用户名连续失败 5 次锁定 15 分钟（Redis 计数）。
- **故障表现**：Redis 不可用时认证不可用（无 DB 兜底），恢复后需重新登录。

## 密码规则

由「平台设置」控制，创建用户、重置密码、修改密码统一校验：

- `password_min_length`：最小长度（默认 6）
- `password_require_upper`：是否必须含大写字母（0/1）
- `password_require_digit`：是否必须含数字（0/1）

## 角色权限

- 权限码定义：`modules/system/permissions.py`（`ALL_PERMISSIONS` / `BUILTIN_ROLES`）。
- 管理员角色启动时自动补全新增权限码，保证“拥有全部权限”。
- 内置角色与默认管理员 `admin/admin123` 由 `core/bootstrap.py` 种子数据初始化。

## 系统设置（四标签页）

设置项按 `settings.type` 列分组（`deploy` / `nginx` / `middleware` / `platform`）：

- `GET /api/settings/list?type=deploy|nginx|middleware|platform` 按组返回，不带 type 返回全部。
- 设置直连 MySQL 读取（无 Redis 缓存）；密码类字段不返回明文。
- `agent_comm_secret` 为只读字段，接口禁止修改（改动会导致所有 Agent 通讯失效）。

## 核心表

| 表 | 说明 |
|---|---|
| `users` | 用户（username/nickname/password_hash/role_id/is_active） |
| `roles` | 角色（name/permissions JSON/is_builtin） |
| `settings` | 系统设置（key/type/value/description） |

## 主要接口

- `/api/auth/login`、`/api/auth/logout`、`/api/auth/me`、`/api/auth/change-password`
- `/api/users/*`：用户 CRUD、重置密码
- `/api/roles/*`：角色 CRUD、权限列表
- `/api/settings/*`：设置查询/更新/调试/连接测试
- `/health`：健康检查（含 Redis 状态）

## 关键文件

- `core/security.py`（鉴权钩子）、`modules/system/session_cache.py`（会话缓存）
- `modules/system/settings_service.py`（缓存与密码规则）、`settings_groups.py`（分组定义）
- `core/bootstrap.py`（种子数据与自动迁移）

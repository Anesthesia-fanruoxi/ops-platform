# 数据字典

> 统一汇总各业务模块的数据库表结构。业务数据唯一事实源为 MySQL 8（InnoDB），认证会话不落 MySQL（存 Redis）。

## 总览

| 模块 | 表 |
|---|---|
| 系统管理 | roles、users、settings、synced_users、menus、audit_logs、super_admins |
| 部署管理 | projects、environments |
| Nginx | nginx_configs |
| CI/CD | cicd_credentials、cicd_dockerfile_templates、cicd_flow_templates、cicd_agents、cicd_builds、cicd_schedule_logs |
| 数据库工具 | collation_datasources、ddl_sync_tasks、ddl_sync_logs |

## 系统管理

### roles（角色表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(50) | 角色名，唯一 |
| description | varchar(200) | 描述 |
| permissions | text | 权限码 JSON 数组，如 `["page:users","op:users"]` |
| is_builtin | bool | 内置角色 |
| created_at | datetime | 创建时间 |

### users（用户表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| username | varchar(80) | 用户名，唯一 |
| nickname | varchar(80) | 昵称 |
| nickname_pinyin | varchar(128) | 昵称拼音（搜索用） |
| password_hash | varchar(256) | 密码哈希 |
| auth_uid | varchar(64) | 统一鉴权中心账号 ID（SSO 用户，唯一） |
| auth_source | varchar(16) | `local` 本地 / `sso` 鉴权中心映射 |
| phone | varchar(20) | 手机号（认证中心同步） |
| email | varchar(128) | 邮箱（认证中心同步） |
| role_id | int | 角色外键 |
| is_active | bool | 是否启用 |
| created_at | datetime | 创建时间 |

### settings（系统设置表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| key | varchar(100) | 设置键，唯一 |
| type | varchar(20) | 分组：`deploy`/`nginx`/`middleware`/`internal` |
| value | text | 设置值 |
| description | varchar(200) | 描述 |
| created_at / updated_at | datetime | 创建/更新时间 |

### synced_users（认证中心用户只读副本）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| uid | varchar(64) | 认证中心用户 ID，唯一 |
| username | varchar(64) | 用户名 |
| nickname / nickname_pinyin | varchar | 昵称 / 拼音 |
| phone / email | varchar | 手机号 / 邮箱 |
| status | int | 1 启用 0 禁用 |
| created_at | datetime | 认证中心侧创建时间 |
| last_synced_at | datetime | 本地同步时间 |

> 本表只读：仅由同步接口 upsert，业务仅查询，不参与登录。

### menus（菜单表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| parent_id | int | 父菜单，NULL=顶层分组 |
| name | varchar(64) | 菜单/分组名 |
| path | varchar(128) | 子菜单路由 |
| icon | varchar(16) | 分组图标 |
| perm_code | varchar(64) | 页面权限码 `page:xxx` |
| op_codes | text | 操作权限 JSON `[{"code":"op:xxx","label":"..."}]` |
| sort | int | 排序 |
| is_builtin / is_active | bool | 内置（不可删）/ 启用 |

### audit_logs（审计日志表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| user_id / username | int / varchar | 操作用户 ID / 冗余用户名 |
| module | varchar(50) | 模块（auth/user/role/credential/setting...） |
| action | varchar(50) | 动作（login/logout/create/update/delete...） |
| method / path | varchar | HTTP 方法 / 请求路径 |
| params | text | 参数 JSON（脱敏） |
| detail | varchar(500) | 动作描述 |
| result | varchar(20) | success / failed / denied |
| diff | text | 字段级变更 JSON（old/new） |
| ip / latency_ms | varchar / int | 来源 IP / 耗时 |
| created_at | datetime | 创建时间 |

### super_admins（超级管理员表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| username | varchar(80) | 用户名，唯一 |
| password_hash | varchar(255) | 密码哈希 |
| nickname | varchar(80) | 昵称 |
| is_active | bool | 是否启用 |
| created_at / updated_at | datetime | 创建/更新时间 |

> 本地逃生账号，独立于认证中心用户，认证中心不可用时仍可登录，仅拥有系统管理权限。

## 部署管理

### projects（项目表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(50) | 项目名，唯一 |
| description | varchar(200) | 描述 |
| created_at | datetime | 创建时间 |

### environments（环境表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| project_id | int | 项目外键 |
| name | varchar(50) | 环境名（项目+环境名唯一） |
| domain | varchar(100) | 域名 |
| port_start | int | 起始端口 |
| nacos_namespace | varchar(200) | Nacos 命名空间 |
| seata_nacos_namespace | varchar(200) | Seata Nacos 命名空间 |

| deploy_config | text | 部署参数 JSON（服务清单/端口/中间件/OSS/Nacos） |
| created_at | datetime | 创建时间 |

| 字段 | 类型 | 说明 |

## CI/CD

### cicd_credentials（凭据表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(100) | 凭据名，唯一 |
| type | varchar(20) | `password`/`token`/`ssh_key`/`harbor` |
| username | varchar(100) | 用户名 |
| secret | text | AES 加密后的密文 |
| url | varchar(200) | Harbor 类型仓库地址 |
| description | varchar(200) | 描述 |
| created_at / updated_at | datetime | 创建/更新时间 |

### cicd_dockerfile_templates（Dockerfile 模板表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(100) | 模板名，唯一 |
| project_type | varchar(20) | `java`/`node`/`go` |
| base_image | varchar(200) | 基础镜像 |
| content | text | 带占位符的模板内容 |
| is_builtin | bool | 内置模板 |
| description | varchar(200) | 描述 |

### cicd_flow_templates（流程模板表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| project_id | int | 项目外键，唯一（1:1 项目） |
| project_type | varchar(20) | `frontend`/`backend` |
| configs | text | 前后端双份配置 JSON `{"backend":{...},"frontend":{...}}` |
| description | varchar(200) | 描述 |
| created_at / updated_at | datetime | 创建/更新时间 |

> `configs` 为唯一数据源，历史顶层字段（language/git_url/build_command 等）已并入 configs。

### cicd_agents（构建节点表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(100) | 节点名，唯一 |
| host | varchar(100) | 主机地址 |
| token | varchar(128) | 节点 token，唯一 |
| install_status | bool | 是否已安装 |
| disabled | bool | 手动禁用（禁止调度） |
| max_concurrent | int | 最大并发 |
| port | int | Agent 任务/日志端口（默认 9090） |
| ssh_port / ssh_username / ssh_auth_type / ssh_credential_id | int/varchar | SSH 连接信息 |
| work_dir | varchar(200) | 工作目录（默认 `/data/cicd`） |
| master_url | varchar(200) | Master 回推地址 |
| frontend_mount_dir | varchar(255) | 前端挂载目录（NFS web 发布目标） |
| nfs_server / nfs_share | varchar | NFS 服务器 / 共享目录 |
| keep_builds | int | 构建记录/目录保留数（默认 5） |
| harbor_credential_id / harbor_type / harbor_url / harbor_user / harbor_pass / harbor_ip | 混合 | Harbor 凭据配置（密码 AES 加密） |
| created_at | datetime | 创建时间 |

> 本表仅存安装配置；在线状态/指标/负载全部存 Redis 心跳。

### cicd_builds（构建记录表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| build_no | varchar(50) | 构建编号，唯一 |
| project_id / environment_id / agent_id | int | 项目/环境/节点外键 |
| branch | varchar(200) | 分支 |
| project_type | varchar(20) | `frontend`/`backend` |
| language | varchar(30) | 语言快照 |
| steps_snapshot | text | 完整步骤配置 JSON 快照 |
| image_name / image_tag / image_digest | varchar | 镜像名 / tag / digest |
| status | varchar(20) | `pending`/`running`/`success`/`failed`/`cancelled` |
| cancel_requested | bool | 取消意图标记 |
| log_file | varchar(300) | 日志文件路径 |
| triggered_by | varchar(80) | 执行人 |
| error_msg | text | 错误信息 |
| started_at / finished_at / duration | datetime / float | 开始/结束时间/耗时（秒） |
| created_at | datetime | 创建时间 |

### cicd_schedule_logs（调度日志表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| build_id / build_no | int / varchar | 构建外键 / 编号 |
| project_name / environment_name | varchar | 项目/环境名 |
| branch | varchar(200) | 分支 |
| triggered_by | varchar(80) | 触发人 |
| status | varchar(20) | `dispatching`/`dispatched`/`no_agent`/`failed` |
| selected_agent | varchar(100) | 最终选中节点名 |
| detail_logs | text | 详细调度日志（按行） |
| created_at | datetime | 创建时间 |

## 数据库工具

### collation_datasources（自定义数据源表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(100) | 数据源名称 |
| host / port / user / password | varchar/int | 连接信息 |
| project / env | varchar(100) | 所属项目 / 环境（分组用） |
| description | varchar(500) | 备注 |
| created_at / updated_at | datetime | 创建/更新时间 |

### ddl_sync_tasks（DDL 同步任务表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| name | varchar(100) | 任务名 |
| project | varchar(100) | 所属项目 |
| database | varchar(100) | 统一库名（各源同步同名库） |
| sources | text | JSON 数组：勾选的数据源 instance_id 列表 |
| ignored | text | JSON 数组：忽略同步的 instance_id 子集（只发不收） |
| positions | text | JSON：各源 binlog 位点 |
| enabled | bool | 是否启用 |
| created_at / updated_at | datetime | 创建/更新时间 |

### ddl_sync_logs（DDL 同步日志表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| task_id | int | 任务外键 |
| source_id | varchar(64) | 变更源 instance_id |
| target_id | varchar(64) | 兼容保留字段 |
| targets | text | JSON：各目标执行结果 `[{id,name,status,error}]` |
| schema_name | varchar(100) | 库名 |
| ddl_type | varchar(32) | CREATE/ALTER/DROP/RENAME 等 |
| sql_text | text | DDL 原文（截断 4KB） |
| status | varchar(16) | `ok`/`failed`/`skipped` |
| error | text | 错误信息 |
| created_at | datetime | 创建时间 |

## 说明

- 所有表使用 InnoDB，行级锁，避免心跳/SSE 写事务互相阻塞。
- 表结构变更由 `core/bootstrap.py` 在启动时做字段级自动迁移（新增字段安全追加）。
- 认证会话不在任何表中（存 Redis `ops:platform:auth:token:{token}`）。

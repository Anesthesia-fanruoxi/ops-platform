# 部署管理模块

> 覆盖：项目/环境管理、K8s YAML 生成、中间件、NFS/Harbor/Nacos 集成、服务信息查看、环境回收

## 功能概览

| 子功能 | 说明 |
|---|---|
| 项目管理 | 项目增删改查，项目下环境按 `{项目}-{环境}` 组织产物目录 |
| 环境创建 | 新建模式 / 复制模式（从源环境复制配置与数据） |
| YAML 生成 | 根据环境配置生成 deployment / middleware / service YAML 并同步 |
| 中间件 | nacos / mysql-nfs / redis / mysql / rabbitmq / kafka |
| 环境管理 | 同步导入、运行/回收站视图、批量回收/恢复/彻底删除 |
| 服务信息 | 服务列表、Pod 日志、部署 YAML、Nacos 配置查看与发布 |
| 自动部署 | 构建成功后远程改镜像 tag + `kubectl apply`（同环境串行） |

## 核心机制

### 部署模式

- **新建模式**：生成 YAML → 创建中间件 → 创建服务。
- **复制模式**：额外执行 MySQL PVC 数据同步（停止 MySQL → `cp` 数据 → 启动），业务库数据保留。

详细流程（8 步、异常处理、回滚）见「部署流程.md」。

### YAML 产物

输出到 `product/{项目}-{环境}/`：

```text
{项目}-{环境}/
├── deployment/   # 各服务 deployment.yaml
├── middleware/   # mysql.yaml / nacos.yaml / redis.yaml 等
└── service/      # 各服务 service.yaml
```

模板位于 `modules/deploy/templates/`（deployment_mod.yaml、mysql.yaml、nacos.yaml、public-config.yaml 等）。

### 配置载体

- `environments.deploy_config`（JSON）：服务清单、端口、中间件、OSS/Nacos 等环境级配置。
- `projects_config.py`：静态定义各项目（ysh/jxh/xafq 等）的服务清单、中间件、各环境端口与 Nacos 命名空间等固定参数。
- 系统设置：NFS / Harbor / K8s / OSS / 域名等全局配置。

### 服务信息查看

- `kube_client.py` 基于 kubeconfig 直连 K8s API Server，提供 Pod 日志、部署 YAML 读取。
- `nacos_http_client.py` 封装 Nacos Open API HTTP 客户端（配置查看/修改，token 缓存）。
- 前端 `ServiceInfoPage.js` 提供服务列表、Pod 日志 SSE、YAML 与 Nacos 配置查看/发布。

### 自动部署

- 构建成功（镜像已推送 Harbor）后由 Master 通过 SSH 修改远程 YAML 镜像 tag 并 `kubectl apply`。
- 同环境使用 Redis 分布式锁串行（`ops:platform:lock:deploy:{项目}-{环境}`），Redis 不可用时降级进程锁。

## 核心表

| 表 | 说明 |
|---|---|
| `projects` | 项目（name 唯一） |
| `environments` | 环境（项目+环境名唯一，deploy_config JSON，回收标记） |

## 主要接口

**部署动作**（`/api/deploy`）

- `POST /execute/project|env|service`：新增项目/环境/服务部署
- `GET /stream`、`GET /status`：部署日志 SSE、部署状态
- `POST /recycle|restore|permanent-delete`：环境回收 / 恢复 / 彻底删除
- `POST /batch-recycle|batch-restore|batch-permanent-delete`：批量回收 / 恢复 / 删除

**环境管理**（`/api/manage`）

- `GET /environments/list|deleted`：环境列表 / 已删除环境
- `GET /validate/project|environment|service`：项目 / 环境 / 服务名校验
- `GET /environments/source-info|available-port|detail`：源环境信息 / 可用端口 / 环境详情
- `POST /environments/refresh`：环境同步（远程下载 → 目录扫描 → 入库/清理）

**项目**（`/api/project`）

- `GET /list`、`POST /update`、`POST /refresh`：项目列表 / 更新 / 刷新

**Harbor**（`/api/harbor`）

- `POST /create-project`、`GET /list-projects`：建项目 / 列表
- `GET /get-project/<name>`、`DELETE /delete-project/<name>`：查询 / 删除
- `GET /list-repositories/<name>`、`GET /list-artifacts/...`：仓库 / 制品列表
- `POST /setup-cleanup`：清理策略

**Nacos**（`/api/nacos`）

- `GET /list-namespaces`、`GET /get-namespace/<id>`：命名空间列表 / 详情
- `POST /create-namespace|copy-namespace`：创建 / 复制命名空间
- `DELETE /delete-namespace/<id>`：删除命名空间

**NFS**（`/api/nfs`）

- `POST /create-dirs|check-dirs`：批量创建 / 校验目录
- `POST /create-single-dir|check-single-dir`：单个创建 / 校验目录

**服务信息**（`/api/deploy/service-info`）

- `GET /list`：服务列表
- `GET /log/stream`：Pod 日志 SSE
- `GET /yaml`：部署 YAML
- `GET/POST /nacos/config`：Nacos 配置查看 / 发布

**管理辅助**（`/api/admin`）

- 项目 / 环境管理辅助接口

## 关键文件

- `modules/deploy/services/`：
  - `deploy_service.py`（部署步骤编排）、`deploy_tasks.py`（后台部署/回收/恢复/删除）、`deploy_utils.py`（任务管理与日志）
  - `yaml_generator.py`（YAML 渲染）、`k8s_service.py`（SSH 连 K8s Master 文件同步与 kubectl）
  - `nfs_service.py`（SSH 建目录）、`harbor_client.py`（Harbor 客户端）、`nacos_service.py`（Nacos 数据库操作）
  - `kube_client.py`（K8s API 直连）、`nacos_http_client.py`（Nacos HTTP 客户端）
- `modules/deploy/templates/`（YAML 模板）、`projects_config.py`（项目静态配置）
- `modules/deploy/api/yaml_api.py`：YAML 生成处理函数，当前未在 routes.py 注册路由（内部调用）
- `static/js/modules/deploy/`：ManagePage.js、CreateProject.js、CreateEnvironment.js、CreateService.js、ServiceInfoPage.js

## 注意

- 回收/彻底删除为高风险操作，执行前确认目标环境。
- MySQL 数据复制仅支持同版本 MySQL（直接复制 PVC 目录）。

# 部署管理模块

> 覆盖：项目/环境管理、K8s YAML 生成、中间件、NFS/Harbor/Nacos 集成、环境回收

## 功能概览

| 子功能 | 说明 |
|---|---|
| 项目管理 | 项目增删改查，项目下环境按 `{项目}-{环境}` 组织产物目录 |
| 环境创建 | 新建模式 / 复制模式（从源环境复制配置与数据） |
| YAML 生成 | 根据环境配置生成 deployment / middleware / service YAML 并同步 |
| 中间件 | nacos / mysql-nfs / redis / mysql / rabbitmq / kafka |
| 环境管理 | 同步导入、运行/回收站视图、批量回收/恢复/彻底删除 |
| 自动部署 | 构建成功后远程改镜像 tag + `kubectl apply`（同环境串行） |

## 核心机制

### 部署模式

- **新建模式**：生成 YAML → 创建中间件 → 创建服务。
- **复制模式**：额外执行 MySQL PVC 数据同步（停止 MySQL → `cp` 数据 → 启动），业务库数据保留。

### YAML 产物

输出到 `product/{项目}-{环境}/`：

```text
{项目}-{环境}/
├── deployment/   # 各服务 deployment.yaml
├── middleware/   # mysql.yaml / nacos.yaml / redis.yaml 等
└── service/      # 各服务 service.yaml
```

模板位于 `modules/deploy/templates/`（deployment_mod.yaml、mysql.yaml、nacos.yaml、public-config.yaml 等）。

### 配置载体

- `environments.deploy_config`（JSON）：服务清单、端口、中间件、OSS/Nacos 等环境级配置。
- 系统设置：NFS / Harbor / K8s / OSS / 域名等全局配置。

### 自动部署

- 构建成功（镜像已推送 Harbor）后由 Master 通过 SSH 修改远程 YAML 镜像 tag 并 `kubectl apply`。
- 同环境使用 Redis 分布式锁串行（`ops:platform:lock:deploy:{项目}-{环境}`），Redis 不可用时降级进程锁。

## 核心表

| 表 | 说明 |
|---|---|
| `projects` | 项目（name 唯一） |
| `environments` | 环境（项目+环境名唯一，deploy_config JSON，回收标记） |

## 主要接口

- `/api/manage/*`：环境列表、回收/恢复/彻底删除
- `/api/deploy/*`：部署动作、同步导入、批量操作
- `/api/project/*`：项目 CRUD
- `/api/harbor/*`：Harbor 仓库/镜像
- `/api/nacos/*`：Nacos 命名空间复制
- `/api/nfs/*`：NFS 目录与 PVC 数据同步
- `/api/admin/*`：管理辅助接口

## 关键文件

- `modules/deploy/services/deploy_tasks.py`（部署主流程）、`yaml_generator.py`（YAML 渲染）
- `modules/deploy/services/k8s_service.py` / `nfs_service.py` / `harbor_client.py` / `nacos_service.py`
- `modules/deploy/templates/`（YAML 模板）

## 注意

- 回收/彻底删除为高风险操作，执行前确认目标环境。
- MySQL 数据复制仅支持同版本 MySQL（直接复制 PVC 目录）。
